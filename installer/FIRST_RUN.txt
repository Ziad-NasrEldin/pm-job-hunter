PM Job Hunter - First Run

This app runs only on your PC. It opens in the browser at http://127.0.0.1/...
Do not put it on a server or share that URL outside this computer.

Windows SmartScreen
This installer is unsigned. If you see "Windows protected your PC":
1) Click More info
2) Click Run anyway

After install
1) Launch PM Job Hunter from the Start menu or desktop shortcut.
2) A browser tab opens on the PM Search tab.
3) Click "Run PM Collection" to pull Product Owner / PM / APM roles.

Facebook is OFF by default. To turn it on, edit:
  %LOCALAPPDATA%\PMJobHunter\.env.local
set FACEBOOK_ENABLED=true, restart the app, then use Facebook Login
in Quick Actions. Facebook login stores your session cookies on this PC.

Files
Config: %LOCALAPPDATA%\PMJobHunter\.env.local
Data:   %LOCALAPPDATA%\PMJobHunter\data
